GetGranted Chat Widget Demo

Floating Mode - Chat Bubble

Floating Widget Features

  • Chat bubble appears in bottom-right corner
  • Subtle pulse animation draws attention
  • Click to expand into 400px × 560px chat panel
  • Greeting tooltip appears after 3 seconds (dismisses after 10s)
  • Smooth open/close animations
  • Responsive on mobile (full-width panel)

How to Test

Look for the blue chat bubble in the bottom-right corner. Click it to start a conversation!

Try these interactions:

  • Click the bubble to open the chat
  • Type a message and press Enter (or click send)
  • Use Shift+Enter for multi-line messages
  • Click the X button to close the chat
  • Wait a few seconds to see the greeting tooltip

Integration Code

To add this widget to your WordPress site, add this code before the closing </body> tag:

<script src="https://YOUR_RAILWAY_URL/widget/getgranted-widget.js"></script>
<script>
  GetGrantedWidget.init({
    mode: 'floating',
    apiUrl: 'https://YOUR_RAILWAY_URL',
    greeting: true,
    greetingDelay: 3000,
    greetingText: '👋 Curious what grant funding your company could qualify for? I can help you figure that out in a few minutes.',
    position: 'bottom-right'
  });
</script>
Note: Replace YOUR_RAILWAY_URL with your actual Railway deployment URL (e.g., https://your-app.up.railway.app).
