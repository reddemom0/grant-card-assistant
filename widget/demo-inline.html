Integration Code

To add this inline widget to your WordPress /get-started/ page, replace the existing grant calculator form with this code:

<div id="getgranted-chat" data-getgranted-inline></div>
<script src="https://YOUR_RAILWAY_URL/widget/getgranted-widget.js"></script>
<script>
  GetGrantedWidget.init({
    mode: 'inline',
    apiUrl: 'https://YOUR_RAILWAY_URL',
    container: '#getgranted-chat',
    quickActions: [
      "We're a tech company",
      "Construction / trades",
      "Food & beverage",
      "Something else"
    ]
  });
</script>
Note: Replace YOUR_RAILWAY_URL with your actual Railway deployment URL. The data-getgranted-inline attribute tells the floating widget to hide itself when inline is present on the page.

Quick Actions Customization

The quick action chips can be customized to match your target industries or common user segments. Edit the quickActions array in the configuration:

quickActions: [
  "Tech / Software company",
  "Manufacturing",
  "Healthcare / Life sciences",
  "Agriculture / Food & bev",
  "Construction / Trades",
  "Professional services",
  "Something else"
]

Keep the list to 3-6 options for best UX. Users can always type their own response if none of the chips fit.
