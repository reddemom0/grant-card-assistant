# Buy BC Partnership Program - Budget Template Guide (2026 Cycle)

## Overview
This guide provides detailed instructions for completing the Buy BC Budget Template (Excel format). The template must be uploaded with your application to the MNP Application Portal.

---

## Budget Template Structure

### Template Tabs
The Excel template contains 4 tabs:
1. **Instructions** - Overview and general guidance
2. **Activity Types & Outputs** - Eligible activities and KPIs
3. **Budget Template** - Main budget worksheet (YOUR WORK HERE)
4. **Quote #1** (and additional quote tabs as needed)

---

## Tab 1: Instructions (Reference Only)

**Key Points:**
- Provide details on expenses you anticipate incurring during project period (April 1 - November 13, 2026)
- Refer to "Activity Types & Outputs" tab for eligible expense items
- Quotes required for budget items equal to or exceeding $5,000
- Add additional "Quote" tabs if more than one quote needed
- Save completed template and upload to application portal

**Contact for Questions:**
- Program Administration: admin@BuyBCPartnershipProgram.ca

- Digital ads (Google Ads, social media ads, website banners)

## Tab 3: Budget Template (Main Worksheet)

### Column-by-Column Instructions

#### Column A: (Empty - Do Not Use)

#### Column B: Activity Type (Dropdown Menu)
**Select from dropdown:**
- Paid Advertising
- In-Store Demonstrations and Promotions
- Labelling Products or Packaging with Buy BC Logo
- B.C. Focused Market Development Trade Shows and Sales Expositions
- Marketing Collateral and Promotional Materials
- Staff Wages

**Tips:**
- Group similar expenses under same activity type
- Use multiple rows for different outputs within same activity
- Ensure activity aligns with your application narrative

#### Column C: Output
**Describe the specific output/expense item**

**Examples:**
- "Booth Rental - BC Food & Beverage Show"
- "Brochures / Rack Cards"
- "Instagram advertising campaign"
- "Product labels with Buy BC logo - 10,000 units"
- "In-store demo staff wages"

**Tips:**
- Be specific and descriptive
- Reference "Activity Types & Outputs" tab for naming conventions
- Include sufficient detail for reviewers to understand expense

#### Column D: Units
**Enter number of units/quantity**

**Examples:**
- 1 (for booth rental)
- 5000 (for brochures)
- 10 (for demo events)
- 1 (for design service)

**Tips:**
- Must be a number
- Use 1 for single purchases or flat fees
- Calculate total units needed for project period

#### Column E: Unit Cost / Purchase Price
**Enter cost per unit in dollars**

**Examples:**
- $2,000.00 (booth rental)
- $0.85 (per brochure)
- $250.00 (per demo event)
- $3,500.00 (design package)

**Tips:**
- Use actual quoted prices when available
- For estimates, base on market research or past experience
- Items ≥ $5,000 REQUIRE quotes

#### Column F: Details (incl. date incurred)
**Provide additional context and timing**

**Include:**
- Item description
- Supplier/vendor name (if known)
- Date expense will be incurred (MM/YYYY)
- Any relevant specifications

**Examples:**
- "Professional brochure design and printing - ABC Printing - June 2026"
- "BC Food & Beverage Show booth rental - August 15-17, 2026"
- "10,000 product labels with Buy BC logo - XYZ Labels - May 2026"

**Tips:**
- Be specific about timing (must be within April 1 - November 13, 2026)
- Include vendor name if quote is attached
- Explain how item supports project objectives

#### Column G: Quote #
**Reference quote tab number (if applicable)**

**When required:**
- All budget items with TOTAL COST ≥ $5,000 must have a quote

**How to use:**
- Enter "1" if quote is on "Quote #1" tab
- Enter "2" if quote is on "Quote #2" tab
- Leave blank if quote not required (item < $5,000)

**Quote Requirements:**
- Must be from vendor/supplier
- Must include itemized costs
- Must be dated within reasonable timeframe
- Paste image/PDF of quote on corresponding tab

#### Column H: Cost
**FORMULA: Automatically calculates = Units (D) × Unit Cost (E)**

**Do not enter manually - Excel will calculate**

**Example:**
- 5000 brochures × $0.85 = $4,250.00

**Verify:**
- Formula calculates correctly
- Total matches your expectations
- If item ≥ $5,000, quote is provided

#### Column I: Buy-BC Cost-Share (%)
**Enter your cost-share percentage**

**Cost-Share Ratios:**

**Stream 1 (Producers/Processors/Cooperatives):**
- First-time applicants: **50%**
- Returning recipients (2023+): **35%**

**Stream 2 (Industry Associations/Boards/Councils):**
- All applicants: **70%**

**CRITICAL:**
- This percentage represents MINISTRY funding, not your contribution
- Use SAME percentage for all line items
- First-time: Enter 50 in every row
- Returning (2023+): Enter 35 in every row
- Associations: Enter 70 in every row

#### Column J: Buy BC Partnership Program Funding Request ($)
**FORMULA: Automatically calculates = Cost (H) × Cost-Share % (I) / 100**

**Do not enter manually - Excel will calculate**

**Example:**
- $4,250.00 cost × 50% = $2,125.00 Ministry funding

**This column shows:**
- Ministry contribution to each line item
- Total Ministry funding request (sum at bottom)

---

## Row 17: TOTALS

**Total Cost (Column H):**
- Sum of all expenses in your budget
- This is your TOTAL PROJECT COST

**Total Funding Request (Column J):**
- Sum of all Ministry funding requested
- This is the amount you request from Buy BC program
- Must not exceed your maximum eligible amount

**Your Cash Match:**
- Total Cost - Ministry Funding Request = Your contribution
- Verify ratio matches your applicant type

**Example Calculation:**
- Total Project Cost: $20,000
- Ministry Funding (50%): $10,000
- Your Cash Match (50%): $10,000

## Tab 4+: Quote Tabs

### How to Add Quotes

**For each budget item ≥ $5,000:**
1. Create or use existing "Quote #" tab
2. Paste image or PDF screenshot of quote
3. Ensure quote includes:
   - Vendor/supplier name and contact
   - Itemized costs
   - Date of quote
   - Terms and conditions (if applicable)
4. Reference quote number in Column G of budget template

**Quote Tab Organization:**
- Quote #1: First quote
- Quote #2: Second quote (add tab if needed)
- Quote #3: Third quote (add tab if needed)
- Continue as needed

**Quote Quality:**
- Professional quotes from legitimate vendors
- Recent dates (within past 6 months ideally)
- Itemized breakdown of costs
- Clear and legible

## Budget Planning Best Practices

### 1. Activity-Specific Considerations

**Paid Advertising:**
- Get quotes from advertising platforms (Google, Facebook, etc.)
- Include production costs (creative, copywriting, design)
- Consider ongoing campaign management
- Plan for multiple channels for broader reach
- Remember: $5K max for influencer marketing

**In-Store Demonstrations:**
- Budget for demo staff wages (hourly rate × hours)
- Include product samples/ingredients
- Consider promotional materials for demos
- Account for travel to multiple locations
- Include setup/teardown time

**Labelling/Packaging:**
- Design fees (graphic designer)
- Printing costs per unit
- Minimum order quantities
- Sample/proof costs
- Remember: $10K maximum

**Trade Shows:**
- Booth rental costs
- Booth design and construction/rental
- Graphics and signage
- Product samples and shipping
- Staff travel and accommodation (if eligible)
- Event-specific marketing

**Marketing Collateral:**
- Design fees
- Printing/production costs
- Distribution costs (if applicable)
- Digital asset creation
- Remember: $5K maximum ($500 for apparel)

**Staff Wages:**
- Hourly rate or salary allocation
- Only portion of time dedicated to Buy BC activities
- Clear connection to funded activities
- Documentation of tasks performed
- Remember: $2K (producers) or $10K (associations) maximum

### 2. Cost-Effectiveness Tips

- **Bundle services:** Get better rates for larger orders
- **Multi-use materials:** Design items usable across activities
- **Realistic pricing:** Don't underestimate or pad costs
- **Value for money:** Show strong ROI for each expense
- **Competitive quotes:** Get multiple quotes for major expenses

### 3. Budget-to-Activity Alignment

**Ensure each budget line:**
- Directly supports a project objective
- Connects to described activities in application
- Contributes to stated KPIs
- Occurs within project period (April 1 - Nov 13, 2026)
- Features Buy BC logo prominently

### 4. Common Budget Mistakes

❌ **Exceeding activity caps**
- Check limits before finalizing budget
- Labelling: $10K, Collateral: $5K, Influencers: $5K

❌ **Missing quotes for items ≥ $5,000**
- Every line item ≥ $5K needs a quote
- Include quote reference in Column G

❌ **Incorrect cost-share ratio**
- Returning recipients: 35%, not 50%
- Associations: 70%, not 50%
- Use same ratio for ALL line items

❌ **Vague expense descriptions**
- Be specific in Output (Column C) and Details (Column F)
- Reviewers need to understand exactly what you're purchasing

❌ **Ineligible expenses**
- General operations/overhead
- Activities outside BC
- Expenses outside project period
- Items without Buy BC logo

❌ **Unrealistic unit costs**
- Use market rates or actual quotes
- Don't underestimate to stay under maximum

❌ **Poor budget justification**
- Every line should connect to application narrative
- Explain how expense supports objectives

### 5. Budget Review Checklist

Before submitting, verify:
- [ ] All activity types selected from dropdown
- [ ] Outputs clearly described
- [ ] Units and unit costs are realistic
- [ ] Details include vendor, date, and context
- [ ] Quotes provided for all items ≥ $5,000
- [ ] Cost-share % is correct and consistent
- [ ] Totals calculate correctly
- [ ] Activity-specific caps not exceeded
- [ ] All expenses occur within project period
- [ ] Budget aligns with application narrative
- [ ] Buy BC logo featured in all activities
- [ ] Quote tabs properly labeled and filled
